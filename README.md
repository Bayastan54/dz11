# Дз11 — видеособеседование 1 на 1

Сайт на TypeScript и WebRTC. Оба участника открывают одну страницу и нажимают «Войти в комнату». Первый ждёт второго, затем звонок начинается автоматически. Есть локальный предпросмотр, кнопки камеры и микрофона и завершение разговора.

## Запуск
Установите Node.js 22.12 или новее. Откройте терминал в распакованной папке рядом с package.json и выполните:
```bash
npm ci
npm run dev
```
Откройте выведенный адрес localhost в двух окнах браузера. В каждом нажмите «Войти в комнату» и разрешите камеру и микрофон. Используйте наушники, чтобы избежать эха. Если другая программа или окно удерживает камеру, для проверки используйте два устройства на опубликованном сайте.

## Как работает звонок
В src/main.ts соединение с wss://inai-col3.fishrungames.com/signaling/ передаёт служебные сообщения. При входе вкладка отправляет hello с отдельным случайным идентификатором. Вторая вкладка отвечает ready. Сравнение идентификаторов выбирает одного отправителя offer даже при одновременном входе. Собеседник принимает offer и отправляет answer. Оба обмениваются ICE-кандидатами, а звук и видео идут через RTCPeerConnection.

Сервер преподавателя общий для всех участников. Если войдёт третий человек, сервер отключит первого. Получив peer-left, оставшийся участник закрывает старое соединение и ждёт следующего. Завершение звонка отключает камеру и микрофон и закрывает WebSocket.

## GitHub Pages
Создайте отдельный пустой публичный репозиторий dz11 под своим GitHub-аккаунтом. В его настройках Settings → Pages выберите GitHub Actions. В корне репозитория должны лежать package.json, package-lock.json и .github/workflows/pages.yml.
Из папки проекта выполните (логин и email возьмите из своего GitHub):
```bash
git init
git config user.name "Ваше имя"
git config user.email "Ваш GitHub noreply email"
git add .
git commit -m "Добавил видеособеседование на WebRTC"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/dz11.git
git push -u origin main
```
Сборка запускается при push в main. Если вы включили Pages после первого запуска, перезапустите workflow. Когда deploy завершится, откройте ссылку из Settings → Pages на двух устройствах. Разрешите камеру и микрофон, проверьте звук и видео в обе стороны. Отключите микрофон, затем выйдите из одной вкладки и войдите повторно.

Для камер браузеру нужен HTTPS или localhost. Сайт использует STUN. Если устройства находятся в сетях, где прямое соединение заблокировано, для работы понадобится TURN-сервер с действующими учётными данными.
